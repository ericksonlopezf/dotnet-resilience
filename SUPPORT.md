# Support Policy

Thank you for using `EricksonLopez.Resilience`!

---

## Community Support Channels

- **GitHub Issues**: Use [GitHub Issues](https://github.com/ericksonlopezf/dotnet-resilience/issues) to report reproducible bugs, request documentation improvements, or submit feature requests.
- **Architecture Documentation**: Comprehensive reference guides, strategy implementations, and integration examples are available in the [`docs/`](docs/) directory.
- **Architecture Decision Records**: Explore design rationale and rejected proposals in [ADRs](docs/decisions/README.md).
- **Executable Showcase**: Explore working examples and production recipes in the [Showcase Reference Application](samples/Showcase/).

---

## Guidelines for Opening Issues

When reporting an issue, please ensure you provide:
1. Exact package version (e.g. `1.0.0`).
2. Target framework (`net8.0`, `net9.0`, or `net10.0`).
3. Minimal reproducible code sample reproducing the issue.
4. Expected vs. actual behavior with full stack traces if applicable.
